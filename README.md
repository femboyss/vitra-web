# vitra-web

Package browser for the **Vitra** package repository.

Live: https://femboyss.github.io/vitra-web
Packages: https://github.com/femboyss/vitra-repo

(c) 2026 34 & Claude. Licensed under GPL-3.0.

This is a static page (GitHub Pages). It reads `packages.json`, which is written by
`vitra-repo/scripts/publish.sh` every time packages are published. The actual package
files are downloaded straight from the vitra-repo GitHub release.
